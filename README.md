# LORDFILM

**LordFilm** — это веб-приложение для управления фильмами, включающее главную страницу с фильмами,страницу с конкретным фильмом и административную панель для авторизованных пользователей.

## 📝 Описание

Приложение предоставляет возможность:
- Просматривать список фильмов на главной странице.
- Просматривать конкретный фильм.
- Управлять фильмами через административную панель (требуется авторизация).

## 🚀 Функциональность

- **Главная страница (/films):** Просмотр фильмов.
- **Административная панель (/admin):** Управление фильмами (только для авторизованных пользователей).

## 📂 Структура проекта

Проект состоит из следующих основных компонентов:

- **`HttpServerLib`:** Библиотека для работы с HTTP-сервером.
- **`MyHttpServer`:** Основное приложение, реализующее функциональность веб-сервера.
- **`MyORMLib`:** Библиотека для работы с ORM (Object-Relational Mapping).
- **`Template_Engine`:** Шаблонизатор для генерации HTML-страниц.
- **`UnitTests`:** Тесты для библиотек и компонентов.

## 🛠 Установка и запуск

1. **Клонирование репозитория:**

   ```bash
   git clone https://github.com/Yuizhey/Semestrovka.git
   cd Semestrovka
2. **Настройка базы данных**:
   - Убедитесь, что у вас установлен **MSSQL**.
   - Создайте базу данных и выполните скрипты из файлов:
     - `Users.sql`
     - `Movies.sql`
     - `MovieDetails.sql`
     - `MovieStatistic.sql`
     - `Producer.sql`
   для создания необходимых таблиц и заполнения их данными.

3. **Сборка и запуск приложения**:
   - Откройте решение `Semestrovka_oris_1.sln` в **Visual Studio** или другом совместимом IDE.
   - Соберите решение и запустите проект `MyHttpServer`.

4. **Доступ к приложению**:
   - Перейдите по адресу `http://localhost:8080/films` для просмотра главной страницы.
   - Для доступа к административной панели перейдите по адресу `http://localhost:8080/admin` (требуется авторизация).
